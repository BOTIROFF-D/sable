# Sable — учебник

Этот текст для тех, кто уже умеет программировать, но Sable видит впервые.
Мы не будем перечислять возможности языка — для этого есть
[справочник](LANGUAGE.md). Вместо этого пройдём путь: от `print("Привет")`
до законченной программы, которая разбирает журнал работ и печатает отчёт.
Каждый шаг решает одну задачу и вводит ровно то, что для этой задачи нужно.

Все примеры ниже — целые программы. Их можно скопировать в файл, запустить
и получить в точности тот вывод, который под ними напечатан.

## 1. Как запускать

Нужен Node 22.6 или новее: TypeScript исполняется нативно, собирать нечего.
Сохраните программу в файл `demo.sable` и запустите из корня репозитория:

```bash
node src/cli.ts demo.sable
```

Ещё два способа пригодятся сразу: одна строка кода без файла и интерактивный
режим, в котором значение последнего выражения печатается само.

```bash
$ node src/cli.ts -e 'print("две в десятой = ${2 ^ 10}")'
две в десятой = 1024
```

```console
$ node src/cli.ts
Sable 0.2.0 — введите выражение, «:помощь» для справки, Ctrl+D для выхода
sable> let часы = [1.5, 2, 0.75]
sable> часы.reduce((a, b) -> a + b, 0)
4.25
sable> :выход
```

Первая программа:

```sable
// Комментарии — как в C. Точки с запятой не нужны: строка и есть конец инструкции.
let кто = "мир"
print("Привет, ${кто}!")

// ${...} — это не подстановка переменной, а любое выражение
print("2 + 2 = ${2 + 2}, и ${"тише".upper()} тоже считается")
```

```text
Привет, мир!
2 + 2 = 4, и ТИШЕ тоже считается
```

Внутри `${…}` можно писать что угодно, включая строки с такими же кавычками —
разбор идёт по скобкам, а не по кавычкам. Это главный способ склеивать текст
в Sable; про остальные — [Строки](LANGUAGE.md#строки).

## 2. Числа и переменные: сколько наработали

Задача: посчитать, сколько часов ушло на задачи за день и во что это обошлось.

```sable
const СТАВКА = 60_000      // сум за час; const менять нельзя, это защита от опечаток
let часы = 1.5 + 2 + 0.75

let деньги = часы * СТАВКА
деньги -= 10_000           // вычли расход на такси

print("Часов за день: ${часы}")
print("Заработано: ${деньги} сум")
print("В среднем на задачу: ${round(часы / 3, 2)} ч")
print("Тысяч сум: ${int(деньги / 1000)}")
```

```text
Часов за день: 4.25
Заработано: 245000 сум
В среднем на задачу: 1.42 ч
Тысяч сум: 245
```

Число в Sable одно — с плавающей точкой, как в JavaScript. Отдельного целого
типа нет, поэтому «целость» получают явно: `int()` отбрасывает дробную часть,
`round(x, знаков)` округляет. Подчёркивания в `60_000` — просто для глаз.

Одна вещь удивляет всех, кто пришёл из JavaScript или Python:

```sable
let деньги = 245000
print("Заработано: " + деньги)
```

```text
Ошибка выполнения: нельзя сложить string и number — приведите к строке через str(...) или вставку ${...}
  --> demo.sable:2:22
  |
2 | print("Заработано: " + деньги)
  |                      ^
```

`+` не смешивает типы. Это сделано специально: молчаливое склеивание строки
с числом — источник ошибок, которые всплывают в проде. Пишите `"${деньги}"`
или `str(деньги)`.

## 3. Ветвление: закрыт ли план

Задача: сравнить отработанное с планом и подписать результат.

```sable
let часы = 4.25
const ПЛАН = 6

// Условие в скобки брать не нужно, а тело — всегда в фигурных.
if часы >= ПЛАН {
  print("план закрыт")
} else if часы >= ПЛАН / 2 {
  print("больше половины")
} else {
  print("день почти пропал")
}

// Тернарный оператор — выражение, поэтому его можно положить в переменную
let значок = часы >= ПЛАН ? "✓" : "…"
print("${значок} ${часы} из ${ПЛАН}")

// Ложны только false и nil. Пустая строка и ноль — истина!
let комментарий = ""
print(комментарий ? "комментарий есть" : "комментария нет")
print(комментарий.len() > 0 ? "комментарий есть" : "комментария нет")

// ?? подставляет запасное значение вместо nil — и только вместо nil
let оценка = nil
print("оценка: ${оценка ?? "не выставлена"}")
```

```text
больше половины
… 4.25 из 6
комментарий есть
комментария нет
оценка: не выставлена
```

Обратите внимание на третью и четвёртую строки вывода: `""` — истина, и это
намеренно. «Пустое значит ложь» — правило, из-за которого `0` и `""` регулярно
проваливаются в неверную ветку; здесь ложны ровно два значения: `false` и `nil`.

## 4. Списки и циклы: очередь задач

Задача: держать список дел, добавлять, перебирать и упорядочивать.

```sable
let задачи = ["форма оплаты", "созвон", "отчёт"]
задачи.push("миграция")

print("Всего: ${задачи.len()}")
print("Первая: ${задачи.first()}, последняя: ${задачи[-1]}")

// Цикл по диапазону, когда нужен номер. Конец диапазона не входит.
for i in 0..задачи.len() {
  print("  ${i + 1}. ${задачи[i]}")
}

// Цикл по значениям, когда номер не нужен
for t in задачи {
  if t.len() <= 6 { continue }
  print("длинная: ${t}")
}

// sort() и slice() возвращают НОВЫЙ список, push() меняет существующий
print(задачи.sort().join(" · "))
print(задачи.slice(0, 2), задачи.contains("созвон"))
```

```text
Всего: 4
Первая: форма оплаты, последняя: миграция
  1. форма оплаты
  2. созвон
  3. отчёт
  4. миграция
длинная: форма оплаты
длинная: миграция
миграция · отчёт · созвон · форма оплаты
["форма оплаты", "созвон"] true
```

Отрицательный индекс отсчитывается с конца: `задачи[-1]` — последняя.
А вот выход за границу — ошибка, а не `nil`: язык предпочитает упасть в том
месте, где ошиблись, а не через десять строк на непонятном `nil`.

Полный список методов — в разделе [Списки](LANGUAGE.md#списки). Стоит запомнить
деление: `push`/`pop`/`insert`/`remove_at` меняют список на месте, всё
остальное возвращает новый.

## 5. Функции: дать имя действию

Задача: привести часы к человеческому виду и посчитать итоги.

```sable
// Значение по умолчанию вычисляется при вызове и видит предыдущие параметры
fn час_текстом(часы, единица = "ч") {
  return часы == int(часы) ? "${int(часы)} ${единица}" : "${часы} ${единица}"
}

fn сумма(числа) { return числа.reduce((a, b) -> a + b, 0) }

let затраты = [1.5, 2, 0.75, 3]

print(затраты.map(x -> час_текстом(x)).join(", "))
print("итого ${час_текстом(сумма(затраты))}")
print("длиннее часа: ${затраты.filter(x -> x > 1).len()} из ${затраты.len()}")
print("самая долгая: ${час_текстом(max(затраты))}")

// Функция — обычное значение: её можно положить в переменную и передать дальше
let в_минуты = x -> round(x * 60)
print(затраты.map(в_минуты))
```

```text
1.5 ч, 2 ч, 0.75 ч, 3 ч
итого 7.25 ч
длиннее часа: 3 из 4
самая долгая: 3 ч
[90, 120, 45, 180]
```

Функцию-значение можно записать тремя способами, и все три означают одно:

```sable
let a = fn(x) { return x * x }   // полная запись
let b = fn(x) -> x * x           // тело-выражение
let c = x -> x * x               // один параметр — скобки не нужны
let d = (x, y) -> x * y          // несколько параметров

print(a(5), b(5), c(5), d(2, 3))
```

```text
25 25 25 6
```

Стрелка `->` берёт **выражение**, а не блок. Нужен блок с несколькими
инструкциями — пишите `fn(x) { … }`.

## 6. Словари: свести часы по проектам

Задача: из плоского журнала получить «проект → часы» и найти, куда ушло больше
всего времени.

```sable
let журнал = [
  { проект: "сайт",  часы: 1.5 },
  { проект: "crm",   часы: 2 },
  { проект: "сайт",  часы: 0.75 },
  { проект: "учёба", часы: 3 },
  { проект: "crm",   часы: 1 },
]

// get(ключ, запасное) — главный приём при накоплении: не нужно заранее
// заводить ключ, достаточно сказать, чего он стоит, когда его ещё нет.
let по_проектам = {}
for запись in журнал {
  по_проектам.set(запись.проект, по_проектам.get(запись.проект, 0) + запись.часы)
}

print(по_проектам)

// Проход по словарю даёт ключи; порядок — порядок вставки, а не случайный
for проект in по_проектам {
  print("  ${проект.pad_end(8, '.')} ${по_проектам.get(проект)} ч")
}

// entries() превращает словарь в список пар — и его уже можно сортировать
let топ = по_проектам.entries().sort((a, b) -> b[1] - a[1]).first()
print("больше всего: ${топ[0]} (${топ[1]} ч)")
```

```text
{"сайт": 2.25, "crm": 3, "учёба": 3}
  сайт.... 2.25 ч
  crm..... 3 ч
  учёба... 3 ч
больше всего: crm (3 ч)
```

Две вещи, на которых спотыкаются:

- `словарь["нет такого ключа"]` — ошибка. Если ключа может не быть, зовите
  `get(ключ, запасное)`.
- Словарь в заголовке `if`/`for`/`while` нужно взять в скобки, иначе `{`
  прочитается как начало тела: `for k in ({ a: 1 }) { … }`.

## 7. Структуры: когда полей стало много

Словари хороши, пока данные разнородные. Как только у всех записей одинаковый
набор полей и появляются операции над ними — пора заводить структуру.

```sable
struct Задача {
  описание
  проект = "разное"        // поля могут иметь значение по умолчанию
  часы = 0
  сделана = false

  fn значок() { return self.сделана ? "✓" : "·" }
  fn строка() { return "${self.значок()} ${self.описание.pad_end(22, ' ')} ${self.проект} · ${self.часы} ч" }

  // Метод может менять поля; вернём self, чтобы вызовы складывались в цепочку
  fn потратить(часов) { self.часы += часов; return self }
  fn закрыть() { self.сделана = true; return self }
}

let t = Задача("починить форму оплаты", "сайт")
print(t.строка())

t.потратить(1.5).потратить(0.25).закрыть()
print(t.строка())

print(type(t), Задача("прочее").проект)

// Две структуры равны, если равны все поля
print(Задача("a", "x") == Задача("a", "x"))
```

```text
· починить форму оплаты  сайт · 0 ч
✓ починить форму оплаты  сайт · 1.75 ч
Задача разное
true
```

Значение по умолчанию вычисляется **при каждом создании экземпляра**, поэтому
`часы = 0` и даже `история = []` безопасны: общего на всех списка не получится.

Присваивание несуществующему полю — ошибка, а не создание нового поля.
Это ловит опечатки вроде `t.сделано = true`.

## 8. Строки: разобрать входные данные

Задача: превратить строку журнала в структуру. Данные приходят текстом, и это
самая частая работа в жизни программы.

```sable
const СТРОКА = "2026-08-21 | done | сайт | A | починить форму оплаты | 1.5"

fn разобрать(строка) {
  // split даёт список; map/trim убирают пробелы вокруг каждой части
  let части = строка.split("|").map(c -> c.trim())
  return {
    дата: части[0],
    сделана: части[1] == "done",
    проект: части[2],
    важность: части[3],
    описание: части[4],
    // num(строка, запасное) не падает на мусоре, а возвращает запасное
    часы: num(части[5], 0),
  }
}

let з = разобрать(СТРОКА)
print(з.проект, з.часы, з.сделана)

// Выравнивание колонок — pad_end/pad_start, повтор — умножением
print("-" * 44)
print("${з.дата}  ${з.описание.pad_end(26, '.')} ${str(з.часы).pad_start(5, ' ')} ч")
print("-" * 44)

// Строки неизменяемы: любой «изменяющий» метод возвращает новую строку
let слово = "  Отчёт  "
print("[${слово.trim().lower()}] длина ${слово.trim().len()}")
print("день: ${з.дата.slice(8)}, месяц: ${з.дата.slice(5, 7)}")
```

```text
сайт 1.5 true
--------------------------------------------
2026-08-21  починить форму оплаты.....   1.5 ч
--------------------------------------------
[отчёт] длина 5
день: 21, месяц: 08
```

Длина и индексы считаются в символах, а не в байтах, поэтому кириллица режется
без сюрпризов: `"Отчёт".len()` — это 5, а не 9.

## 9. Замыкания: функция, которая помнит

Задача: собрать статистику по ходу дела и научиться делать фильтры на лету.

```sable
// Функция, возвращающая функцию: фильтр собирается под конкретный проект
fn из_проекта(имя) { return з -> з.проект == имя }

// Замыкание помнит своё окружение: «всего» живёт между вызовами,
// но снаружи к нему не добраться иначе, как через возвращённые функции.
fn накопитель() {
  let всего = 0
  let было = 0
  return {
    добавить: fn(x) { всего += x; было += 1; return всего },
    среднее: () -> было == 0 ? 0 : round(всего / было, 2),
    итог: () -> всего,
  }
}

let журнал = [
  { проект: "сайт", часы: 1.5 },
  { проект: "crm",  часы: 2 },
  { проект: "сайт", часы: 0.75 },
]

print("по сайту записей: ${журнал.filter(из_проекта("сайт")).len()}")

let acc = накопитель()
for з in журнал { acc.добавить(з.часы) }
print("итого ${acc.итог()} ч, в среднем ${acc.среднее()} ч")

// Каждая итерация for получает СВОЮ переменную цикла
let отложенные = []
for i in 0..3 { отложенные.push(() -> i * 10) }
print(отложенные.map(f -> f()))
```

```text
по сайту записей: 2
итого 4.25 ч, в среднем 1.42 ч
[0, 10, 20]
```

Последний пример стоит запомнить: в языках, где переменная цикла одна на все
итерации, `[0, 10, 20]` превращается в `[20, 20, 20]`. Здесь — нет.

## 10. Ошибки: как падать понятно

Задача: не дать записать в день больше часов, чем в нём есть.

```sable
fn списать(остаток, часы) {
  assert(часы > 0, "часы должны быть положительными, получено ${часы}")
  if часы > остаток {
    error("нужно ${часы} ч, а в дне осталось ${остаток}")
  }
  return остаток - часы
}

let день = 8
день = списать(день, 3)
день = списать(день, 2)
print("осталось ${день} ч")

день = списать(день, 5)
print("сюда мы уже не дойдём")
```

```text
осталось 3 ч
Ошибка выполнения: нужно 5 ч, а в дне осталось 3
  --> demo.sable:4:10
  |
4 |     error("нужно ${часы} ч, а в дне осталось ${остаток}")
  |          ^
  в списать (demo.sable:14:15)
```

Ошибка показывает, что случилось, где именно и через какие вызовы туда пришли.
`assert(условие, сообщение)` — для того, что не должно случаться никогда;
`error(значение)` — для отказа по делу.

Ошибка останавливает программу. Поэтому для **ожидаемых** неудач — «не нашли»,
«не разобрали» — удобнее возвращать `nil` и разбирать его на месте:

```sable
let журнал = [{ проект: "сайт", часы: 1.5 }, { проект: "crm", часы: 2 }]

fn часы_проекта(журнал, имя) {
  let найдено = журнал.find(з -> з.проект == имя)
  return найдено == nil ? nil : найдено.часы
}

print("сайт: ${часы_проекта(журнал, "сайт") ?? "нет записей"}")
print("склад: ${часы_проекта(журнал, "склад") ?? "нет записей"}")
```

```text
сайт: 1.5
склад: нет записей
```

Что именно из средств обработки ошибок есть в вашей версии — смотрите раздел
[Ошибки](LANGUAGE.md#ошибки) справочника.

## 11. Собираем целиком: отчёт по журналу

Теперь сложим всё вместе. Программа читает журнал работ в текстовом виде,
превращает его в структуры, проверяет данные и печатает отчёт: сводку по дням,
разбивку по проектам с гистограммой и список того, что осталось.

```sable
// ---- данные ---------------------------------------------------------------
// дата | статус | проект | важность | описание | часы

const ЖУРНАЛ = `
2026-08-17 | done | сайт   | A | починить форму оплаты      | 2.5
2026-08-17 | done | crm    | B | созвон с клиентом          | 1
2026-08-18 | done | сайт   | C | подписи к картинкам        | 0.5
2026-08-18 | open | crm    | A | миграция базы              | 4
2026-08-18 | done | учёба  | B | глава про замыкания        | 1.5
2026-08-19 | done | crm    | A | миграция базы              | 3
2026-08-19 | open | сайт   | B | ревью вёрстки              | 1
2026-08-20 | done | учёба  | C | конспект                   | 0.75
2026-08-20 | open | crm    | A | отчёт по инциденту         | 2
`

const ВАЖНОСТЬ = { A: "срочно", B: "обычно", C: "потом" }

// ---- модель ---------------------------------------------------------------

struct Работа {
  дата
  сделана
  проект
  важность
  описание
  часы

  fn значок() { return self.сделана ? "✓" : "·" }
  fn строка() {
    return "${self.значок()} ${self.описание.pad_end(28, ' ')} ${self.проект.pad_end(7, ' ')} ${str(self.часы).pad_start(4, ' ')} ч"
  }
}

fn разобрать(строка) {
  let ч = строка.split("|").map(c -> c.trim())
  assert(ч.len() == 6, "в строке «${строка}» ${ч.len()} колонок вместо 6")
  assert(ВАЖНОСТЬ.has(ч[3]), "неизвестная важность «${ч[3]}» в строке «${строка}»")
  return Работа(ч[0], ч[1] == "done", ч[2], ч[3], ч[4], num(ч[5], 0))
}

let работы = ЖУРНАЛ.trim().split("\n").map(s -> разобрать(s))

// ---- инструменты ----------------------------------------------------------

fn сгруппировать(список, ключ) {
  let группы = {}
  for x in список {
    let k = ключ(x)
    let корзина = группы.get(k, [])
    корзина.push(x)
    группы.set(k, корзина)
  }
  return группы
}

fn часов(список) { return список.map(w -> w.часы).reduce((a, b) -> a + b, 0) }
fn полоса(часть, целое, ширина) { return "▮" * int(round(часть / целое * ширина)) }

// ---- отчёт ----------------------------------------------------------------

let всего = часов(работы)
let сделано = работы.filter(w -> w.сделана)
let дни = сгруппировать(работы, w -> w.дата)

print("Журнал: ${работы.len()} записей за ${дни.len()} дн., ${всего} ч")
print("Закрыто: ${сделано.len()} (${round(часов(сделано) / всего * 100)}% времени)")

print("\nПо дням")
for день in дни.keys().sort() {
  let за_день = дни.get(день)
  let открытых = за_день.filter(w -> !w.сделана).len()
  let хвост = открытых == 0 ? "всё закрыто" : "${открытых} в работе"
  print("  ${день}  ${str(часов(за_день)).pad_start(5, ' ')} ч  ${хвост}")
}

print("\nПо проектам")
let проекты = сгруппировать(работы, w -> w.проект)
for пара in проекты.entries().sort((a, b) -> часов(b[1]) - часов(a[1])) {
  let имя = пара[0]
  let часы = часов(пара[1])
  print("  ${имя.pad_end(7, ' ')} ${str(часы).pad_start(5, ' ')} ч ${полоса(часы, всего, 24)}")
}

print("\nОсталось сделать")
let открытые = работы.filter(w -> !w.сделана).sort((a, b) -> a.важность < b.важность ? -1 : a.важность > b.важность ? 1 : 0)
for w in открытые {
  print("  ${w.строка()}  ${ВАЖНОСТЬ.get(w.важность)}")
}

// Одна и та же задача может тянуться несколько дней — найдём самую долгую
let по_описанию = сгруппировать(работы, w -> w.описание)
let долгая = по_описанию.entries().sort((a, b) -> часов(b[1]) - часов(a[1])).first()
print("\nДольше всего: «${долгая[0]}» — ${часов(долгая[1])} ч за ${долгая[1].len()} дн.")
```

  2026-08-18      6 ч  1 в работе
  2026-08-19      4 ч  1 в работе
  2026-08-20   2.75 ч  1 в работе

По проектам
  crm        10 ч ▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮

  учёба    2.25 ч ▮▮▮

  · отчёт по инциденту           crm        2 ч  срочно

Здесь нет ничего, чего не было в главах 2–10: строки, списки, словари,
структуры, функции-значения и `assert` на входе. Обратите внимание на две
привычки, которые окупаются на любой программе такого рода. Первая: проверки
стоят в `разобрать`, то есть на границе, где текст превращается в данные, —
дальше по коду можно считать, что поля на месте. Вторая: `сгруппировать`,
`часов` и `полоса` написаны один раз и переиспользованы трижды каждая; именно
это, а не длина файла, отличает отчёт, который не страшно менять.
