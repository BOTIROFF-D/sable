# Поддержка редакторов

## VS Code

Подсветка синтаксиса, комментарии, автозакрытие скобок и отступы.

Установка без публикации в маркетплейс — символьной ссылкой в папку расширений:

```bash
ln -s "$PWD/editors/vscode" ~/.vscode/extensions/dbgo
```

После перезапуска VS Code файлы `.dbgo` подсвечиваются.

Что подсвечивается: ключевые слова, встроенные функции, имена в объявлениях
`fn` / `struct` / `let` / `const`, вызовы, числа (включая `0xFF` и `1_000`),
строки во всех трёх видах кавычек со вставками `${…}` внутри, комментарии,
включая вложенные блочные.

## Согласованность с языком

Списки ключевых слов и встроенных функций в грамматике сверяются с настоящими
списками из `src/token.ts` и из интерпретатора — это делает `node tests/grammar.ts`,
входящий в `npm test`. Добавили слово в язык и забыли про подсветку — сборка
покраснеет. Подсветка обычно устаревает молча, здесь этого не выйдет.

Проверено структурно: все выражения грамматики компилируются, лишних имён нет.
В самом редакторе внешний вид не проверялся — это делается глазами после установки.
